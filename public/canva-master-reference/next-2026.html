4. Format reference

Layout logic, dimensions, and per-division vs. shared-copy notes for each of the 26 formats referenced by number in section 4. Formats 1–13 are the original square/LinkedIn/email-header campaign; 14–25 are the advocacy-square and speaker-card campaign; 26 is the sponsorship packet.

1. Square post (1200×1200)

Media is the only division with a character/hero image (an armored figure, top-right, roughly 723×887px). Decision made to skip sourcing character images for the other 10 divisions.

2. LinkedIn single-image ad — navy (1200×627)

Fixed 2026-07-08: the source template's big background circle was originally a fixed, non-editable shape — it always rendered green (Games' color) regardless of division. The Games source file was manually converted in Canva's UI into a real image frame, producing a new circular element that defaults to Games' accent color. All 10 other divisions were rebuilt fresh from this fixed source with the new circle set to each division's own accent color, alongside the usual headline/body/logo/circlelines/button edits.

3. LinkedIn post — white version (1080×1080)

Uses a white/light gradient background instead of navy, dark navy text instead of white, and a division-specific color logo instead of the reversed white logo used on the navy designs. Accent color, circlelines, and body copy/headline are otherwise identical to the navy formats. See the Life Sci row above.

4. LinkedIn single-image ad — light version (1200×627)

Light/white-background variant of format 2, using the same layout logic as format 3: color logo instead of reversed-white logo, division accent color on the circle/circlelines/button. Template fix on build: the source file (copied from an older Dataforce-based file) still had a leftover headline reading "FOR DATA" instead of "FOR GAMES", plus a duplicate stacked date/venue text box. Both were corrected on the source before any divisions were built from it.

5. LinkedIn post — light version, "white callouts" style (1080×1080)

A distinct light-background layout — centered large body copy, logo bottom-right, CTA bottom-left, vertical rotated headline text along the left edge, and a shared "BEYOND INTELLIGENCE" tagline top-right (kept identical across all divisions per decision, not division-specific). No circlelines or accent-circle elements exist in this layout. Dataforce is the source template; the other 10 were copied fresh and edited: headline, body copy, accent button fill, and color logo fill.

6. Email header — dark v1 (800×250)

Same layout logic as the navy LinkedIn ad (format 2): reversed-white logo, division accent color on both the accent circle and CTA button, division circlelines. Games is the source template; the other 10 were copied fresh and edited: headline, body copy, accent circle fill, CTA button fill, circlelines fill, and logo fill.

7. Email header — dark v2 (800×250)

Styled as an article/webinar promo rather than the standard event-headline pattern. The source template's headline/subhead ("GenAI and Machine Translation in Retail Marketing: Industry Leaders Discuss Real-World Success at GlobalLinkNEXT") plus the "BEYOND INTELLIGENCE" tagline, date/venue, and CTA text all stay identical across every division — a deliberate decision (the copy references GlobalLinkNEXT specifically but sits under each division's own logo/accent/circlelines by design). Only three elements are swapped per division: CTA button fill, circlelines fill, and logo fill.

8. Email header — light v1 (800×250)

Light-background counterpart to format 6: standard per-division headline pattern ("THE NEW PRODUCTION ECOSYSTEM FOR [DIVISION]"), color logo instead of reversed-white, division accent on circlelines and CTA button. Games is the source template; sources were confirmed clean before mass-copying.

9. Email header — light v2 (800×250)

Shares the GenAI/webinar-promo copy pattern with format 7 (headline, subhead, tagline, date/venue, and CTA text identical across all divisions). Only three fills swap per division: CTA button, circlelines, and color logo.

10. Email header — light v3 (800×250)

Standard per-division headline pattern, plus a large circular conference-stage hero photo (shared/decorative asset, not customized per division — consistent with the campaign-wide decision to skip character/hero images). Per-division edits: headline text, CTA button fill, circlelines fill, color logo fill.

11. Email header — light v4 / "white v4" (800×250)

GenAI/webinar-promo shared-copy pattern (like formats 7 and 9), but this layout has no circlelines element. Only two fills swap per division: CTA button and color logo. Games source file is titled "GamesNEXT Email Header white v4" in Canva.

12. Email header — dark v3 (800×250)

Same page/element family as format 10 (light v3): standard per-division headline pattern plus the shared conference-stage hero photo. Navy background, so uses the reversed/white logo asset instead of the color logo. Per-division edits: headline text, CTA button fill, circlelines fill, white logo fill.

13. Email header — dark v4 (800×250)

Same page/element family as format 11 (light v4): GenAI/webinar-promo shared-copy pattern, no circlelines element. Navy background, reversed/white logo asset. Only two fills swap per division: CTA button and white logo.

14–16. Advocacy squares — light (1080×1080)

Three social graphics on a white/light background — "I'm attending," "I'm speaking," "we're sponsoring." Games is the source template for all three.
